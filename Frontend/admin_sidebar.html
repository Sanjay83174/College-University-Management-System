Admin Dashboard

About the Admin Panel

The Admin Dashboard is the control center for university management. It provides tools for user and content management, analytics, and secure access to administrative features.

  • User Management (students, staff, faculty)
  • Content Management (news, events, notices)
  • Analytics & Reports
  • Role-based access control
  • System settings and security

Key Features

  • Add, edit, or remove users
  • Publish news, events, and circulars
  • View analytics and generate reports
  • Manage permissions and roles
  • Monitor system activity logs
